# 可复用经验：把成功和失败都写进流程

## 输入与评估

- 先选择 blind / source-assisted / vendor-reuse 模式。图纸准备阶段已经读过原件，就不能再称同会话独立盲测。
- 提取事实、推断与未解决项；单位、孔是否贯穿、隐藏轮廓和曲面连接对应不清时先澄清。
- 图纸最好包含剖视、孔表、基准与装配接口；独立命名视图加尺寸说明不能冒称标准投影布置或签审生产图。
- 自制件和采购件分开；种类、实例、子装配和配合数量分开。保留供应商 SLDASM 内部关系不算本轮新建成功。

## 建模与几何

- 图纸 mm/in 与 COM m/rad 显式转换；英寸乘 25.4 转 mm，再转 m，不改变角度。
- 创建草图时防止自动推断增加不需要的等长/垂直等关系；全约束之后仍要查尺寸。
- 不跨拓扑变化缓存 Face/Edge 索引；按局部几何匹配也须检查唯一性、面意义和方向。
- 放样截面保持一致环绕顺序与连接点；每次关键放样后查合法实体，而不是只看 Feature Error=0。
- 不因体积接近就接受模型。单件优先实体布尔交集/对称差，配合专门的尺寸、材料和语义检查。
- 输入无法唯一定义曲面时记录假设，不能只调参数追体积，也不能声称体积差必然来自曲率。

## 装配

- 平面实体外法向与底层曲面参数方向分开；有向对齐应使用前者。当前等价面特例不要推广成任意平面规则。
- 固定一个基准，其他组件通过真实配合求解；必须披露使用原始朝向提示，不能描述为仅凭 PDF 猜装。
- 重合和同轴的无向残差无法排除翻转解。检查配合状态之外，还要比较全局位姿、朝向、干涉与残余自由度。
- 局部配合组会整体移动；这不同于建立新的子装配文件。可以按基准向外规划模块顺序，但本轮没有自动优化排序。
- 同一供应商子装配多次实例化时，内部配合按实例计数；共享文档不等于只出现一次内部关系。
- 原模型可能已有干涉。先测基线，再区分继承和新增，不随意把原件当零干涉真值。

## 执行、恢复与效率

- 同一 SolidWorks 会话串行操作。打开/新建/修改前检查文档身份；超时后先读状态，不能盲目重发。
- 留存独立输出，源模型不覆盖。保留采购件副本并重定向引用，保存重开检查所有依赖路径。
- 本轮直接 COM 是已验证路径；MCP 是另一路封装，协议正常、ok=true 和几何正确分属不同层。
- 记录模型与阶段耗时，区分首次/热缓存重跑、模型规划/代码执行/验证/排错。未做 A/B 测试不报告优化百分比。
- 草图欠约束、未分配材料、未验收螺纹都要单列。可编辑原生特征不自动等于生产就绪。

## 录屏与汇报

- 录屏前看一帧实际主屏，确认是否同时显示 Codex 和 SolidWorks；不要只确认录像文件存在。
- 仅在模型界面变化时录制，finally 中正常停止并完成编码；抽帧与完整解码检查。
- 静态展示、核心流程剪辑和全任务录像分别标注。失败/验证可以不放在演示剪辑里，但必须在报告披露。
- 不用“零错误码”“43/43”替代整体结论；用“经一次修正后本例通过”，不用“通用成功率 100%”。

## 模型无关的沉淀边界

稳定的是输入契约、单位、阶段边界、安全约束和验收准则；可变化的是模型的读图解释、特征分解和恢复策略。案例具体尺寸和固定步骤不应该写成全局 Skill 规则。当前部分代码仍有案例绑定，已在 runtime/com/README.md 列明。
