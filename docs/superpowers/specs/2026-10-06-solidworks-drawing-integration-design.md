# SOLIDWORKS 自动制造图草稿设计

将现有工程图 skill 与迁移 skill 的原生标注能力结合，在 SOLIDWORKS 中完成尺寸定义与动态排版，输出供工程师审核的单页 DWG，以及从该 DWG 生成的 PDF 和 PNG。排版参考用户提供的 DWG 图纸库。本文是待审阅的实现设计；既有脚本的能力边界以 skill 中的实际契约为准。

## 确认范围

| 决策 | 要求 |
| --- | --- |
| 输入 | 第一阶段一次一个已保存、未修改的原生 SOLIDWORKS 零件；后续扩展 STEP 等导入实体 |
| 操作 | 用户指定模型后自动完成，问题在结束时集中报告 |
| 输出等级 | 工程师审核用制造图草稿，不自动批准生产发布 |
| 完整性 | 尽量覆盖全部可确定几何特征；无法可靠表达的项目必须明确列出 |
| 制造信息 | 只复用已有模型信息及明确指定的规则，不推测公差、功能基准、螺纹等级、粗糙度 |
| 图幅 | A4、A3、A2，允许横纵向，严格单页；仍放不下时失败并交人工处理 |
| 视图 | 按特征选择必要视图、剖视、反向视图和局部视图，允许省略无额外信息的视图 |
| 投影 | 跟随模板，检查投影标识、视图位置和对齐关系一致 |
| 标注 | 常规尺寸、表格或混合表达均可，按覆盖与可读性选择 |
| 风格 | 按板类、轴类、支架类选择布局，字号、箭头、线型等保持统一；不固定 45°方式 |
| 文件 | DWG 为主要可编辑交换文件，PDF 用于审核，PNG 用于预览；SLDDRW 为内部验证文件 |
| 验收 | 每次执行特征覆盖及输出检查，开发阶段对代表性零件追加盲重建 |

第一阶段不包含装配、BOM、批处理和 STEP 通用特征识别。内部按几何特征及来源记录数据，避免把后续导入实体扩展绑定到原生特征名称，但不提前实现第二套 CAD 内核。

## 技术选择与事实

以 `skills/solidworks-drawing` 为统一入口。保留它的几何检查、计划校验、视图和剖视生成、尺寸关联、保存重开及源文件完整性检查。迁移 skill 中已经存在模型尺寸导入及保存操作；将必要的通用逻辑收敛到工程图执行器，继续调用官方 COM，不建立两个独立驱动同时操控同一会话的流程，也不要求运行时安装整个迁移 skill。

本机已安装的 interop 声明包含下列入口；声明存在不等于业务执行通过，第一阶段需在自建样例上逐一验证。

| 任务 | 接口 | 验证重点 |
| --- | --- | --- |
| DimXpert 检查及方案生成 | `DimXpertManager`、`IDimXpertPart.GetFeatures/GetAnnotations/GetAutoDimSchemeOption/AutoDimensionScheme` | 实际可用性、特征对应、公差来源、源件保护 |
| 已有建模尺寸导入 | `IDrawingDoc.InsertModelAnnotations3` | marked/unmarked 尺寸覆盖、去重、适合的视图 |
| DimXpert 注解导入 | `IView.ImportAnnotations` 的 `IncludeDimXpertAnnotations` 参数 | 注解实际类型、关联、尺寸值和导入前后变化 |
| 原生尺寸自动排列 | `IModelDocExtension.AlignDimensions`，`swAlignDimensionType_AutoArrange` | 仅处理选定维度；排列后读取并检查实际位置 |
| DWG 导出 | `IModelDocExtension.SaveAs3` 及 DXF/DWG 导出设置 | 返回值、错误、字体、线型、比例、纸空间及完整性 |
| DWG 重新导入 | `GetImportFileData`、`IImportDxfDwgData`、`LoadFile4` | 独立读取导出文件，显式固定单位、纸幅、比例和位置 |
| 标注显示信息 | `IAnnotation.GetDisplayData`、`IDisplayData`、`INote.GetExtent` | 实际文字、引线、箭头及表格边界的可测范围 |

`InsertModelAnnotations3` 最后一个参数是 `UsePlacementInSketch`，不能把它当成 DimXpert 开关。DimXpert 注解使用单独的视图导入入口，并核对实际结果。

Auto Dimension Scheme 的公差类型枚举仅有 PlusMinus 和 Geometric，不能假定存在无公差自动模式。[官方枚举](https://help.solidworks.com/2025/english/api/swdimxpertapi/SolidWorks.Interop.swdimxpert~SolidWorks.Interop.swdimxpert.swDimXpertAutoDimSchemeToleranceType_e.html) 提供两种类型；[方案接口](https://help.solidworks.com/2026/english/api/swdimxpertapi/SolidWorks.Interop.swdimxpert~SolidWorks.Interop.swdimxpert.IDimXpertPart~AutoDimensionScheme.html) 要求先取得配置对象。因此有明确制造规则时才运行相应自动方案；否则复用已有 PMI，并从几何建立名义尺寸和缺项清单。单独插入无公差 DimXpert 尺寸可作为待验证原生操作，失败时不得悄悄采用默认公差。

## 数据和执行流程

执行流为：源件检查 → 尺寸与特征清单 → 必要的工作副本及尺寸定义 → 模板与视图选择 → 原生工程图和标注 → 排版反馈 → 原生保存重开 → DWG 导出与重新读取 → PDF → PNG → 最终报告。

每次使用新运行目录。源件只读；需要新增 DimXpert 信息时先复制零件，在副本操作。记录原件与工作副本的身份、配置和来源关系，副本单独检查几何未变。拓扑引用只能用于其所属文档和事实版本，不能把源件引用直接套到新副本。原生工程图引用哪个模型，就保留对应内部模型及图纸，供恢复和验证。

共用一份特征覆盖清单，而不是每个阶段各自猜测尺寸。每项包含：稳定的运行内标识、几何实体证据、应表达的信息、已有尺寸/PMI、选用视图、尺寸或表格行、值及单位、制造信息来源、覆盖状态。只按数值去重不够；实体、尺寸含义和表达方向须一致。

覆盖状态分为 `covered`、`missing_geometry_definition`、`unsupported_operation` 和 `missing_manufacturing_requirement`。已知几何定义缺失或操作不支持会阻止完整草稿通过；缺少未提供的公差等制造要求允许交付待审核草稿，并列明待补项。

## 参考图和模板

从 [用户指定图纸库](https://www.innerscene.com/tools/library/drawings/format/dwg) 筛选机械、带尺寸和标题栏样例，先形成少量可复用布局，不批量复制所有文件。目录标签只用来筛选，必须检查实际内容。参考图私有保存，公开仓库只记录来源链接和通用规则。

每个选定样例提取纸幅和有效区域、标题栏边界、视图排列、比例关系、尺寸分层、引出线方向、文字/箭头/线宽和留白。样例尺寸只用于解释其排版，不能进入用户零件的尺寸或制造要求。

用简单 JSON 保存布局配置：零件类型、投影法、模板路径参数、绘图区及禁入区域、视图相对位置、尺度候选、字号/箭头/线型和标注间距。实际 `.drwdot` 使用当前安装模板的副本并调整；DWG 不能直接当作 `.drwdot`。不在公开配置中写机器绝对路径。

模板负责样式与固定区域，规划器负责动态视图和位置。按模板的投影信息确定约束，检查标题栏符号及视图实际关系。模板缺少可靠投影信息时配置必须补充后才使用。

## 尺寸定义和表格

优先复用已有设计尺寸与 PMI，通过特征及几何枚举检查模型尺寸清单是否完整；不能只依靠迁移 skill 的尺寸遍历计数。按形状表达需要保留制造相关尺寸，筛掉只属于建模过程且没有图纸表达价值的重复量。

补齐范围包括外形、台阶、槽、孔径/孔位/孔深/数量/通盲、圆角和倒角。线程及孔向导信息有明确来源才创建相应孔说明。几何上类似圆孔不能直接推断为螺纹孔。原生关联尺寸优先，文字说明及一般表格的非关联性质必须记录。

表格可以表达密集孔群和其他适合逐项列出的几何定义。每行必须对应图中可见编号或清楚识别的特征，位置值带单位、原点和轴向，保留尺寸、深度、数量等必要字段。仍需在视图表达理解形状所需的剖面和关键轮廓尺寸。

当前 v1 表格契约只接受 `nominal_hole_schedule`。第一阶段扩展为有限的通用特征尺寸表角色，按角色校验必需字段和来源，不使用万能任意表格绕过检查。普通表格不宣称为关联 Hole Table；其数据在保存重开及导出后都重新核对。

## 动态排版

先按特征覆盖选择视图组合，再尝试 A4、A3、A2 的横纵向以及有限的常用比例候选。正投影关联视图保持统一比例和投影关系，局部/轴测可使用单独比例并明确标识。

以模型投影范围计算初始视图尺寸，为尺寸层、引线和表格预留空间，排除图框、标题栏及说明区。创建预览后读取实际视图外框和标注显示数据，使用原生自动排列处理选定尺寸，再用现有外侧尺寸分层规则修正。原生自动排列是局部操作，不当作全图碰撞求解器。[官方示例](https://help.solidworks.com/2025/english/api/sldworksapi/auto-arrange_dimensions_example_csharp.htm?format=P&value=) 明确以选定尺寸为处理对象。

候选先通过硬约束：特征覆盖、单页、A2 上限、模板字号、投影一致、无越界或悬空、表格完整、无妨碍阅读的冲突。再比较纸幅、比例与阅读距离、交叉引线和分布留白，选取更清晰的候选。最小纸幅只是通过硬约束后的偏好，不以缩小文字换取小纸幅。

局部修复顺序为调整标注层及引线、使用表格、移动视图和表格、调整常用比例或图幅。预设候选评估不计作失败重试；执行失败后最多三次有依据的计划修复。不能解决时保留图纸和原因并报告失败。

没有通用的 `IAnnotation.GetBox` 可以直接覆盖所有标注。尺寸/注释文字结合显示数据、字体测量与实际渲染形成保守范围；引线及箭头用显示几何检查。无法测得的项目明确保留视觉审核要求，不把近似文字框检查称为严格无碰撞证明。

## DWG 和审核输出

原生工程图保存重开检查继续保留，SLDDRW 为内部文件。DWG 导出时显式设置版本、字体、线型、活动页、纸空间及比例策略，并在结束后恢复受影响的系统设置。[官方导出选项](https://help.solidworks.com/2020/English/SolidWorks/sldworks/r_dxf_dwg_export_options.htm) 包含字体映射、纸空间和几何 1:1 输出；本流程需要保留工程图页面布局，不能误开几何 1:1 输出导致图框比例改变。

从实际 DWG 独立读取内容，再生成 PDF；PNG 从该 PDF 渲染。首个无需新增二维 CAD 软件的验证路径是使用 SOLIDWORKS 的 DWG 导入能力。[官方接口](https://help.solidworks.com/2024/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IImportDxfDwgData.html?id=0e5daa8afdfc40a9ab2eaa8899b9576e) 允许明确指定纸幅、比例、单位及位置；否则会计算默认值，因此不能直接采用导入默认布局。

DWG 导入、PDF 输出的稳定性是首个技术验证点。导入失败或丢字、符号、尺寸时，DWG 可以保留为未通过审核的结果，整体交付不得判成功。可另附原生图 PDF 作为诊断并注明来源，但不能冒充从 DWG 生成的正式审核 PDF。不自动安装或依赖未验证的外部 CAD 转换器；若原生回读不能满足要求，再提出有证据的替代后端。

验证 DWG/PDF 的单位、图幅、关键几何及尺寸值、文字/符号、表格、线型、比例和完整性。导入后变成图形的尺寸按实际对象类型记录，不宣称仍具有与源三维模型的关联，也不要求每个二维软件表现完全一致。

## 最小实现组织

保留现有 `run.ps1` 的 Inspect、Visibility、Execute、Verify 和 v1 计划兼容性。集成入口增加少量阶段控制，使用同一个串行执行主机及会话锁。模型计算使用 SI，规划与图纸位置使用 mm，转换在 COM 边界完成。

- 扩展检查及计划：完整尺寸/PMI/特征清单、覆盖关系、模板信息、有限视图组合和图幅候选。
- 增加原生标注操作：尺寸导入、DimXpert 信息与受控生成、剖视/局部视图、自动排列和特征表。
- 增加导出及回读操作：DWG 设置快照/恢复、导出、DWG 重新读取、PDF/PNG及报告。

新增能力通过明确阶段和字段接入，先完成契约校验与对应 C# 操作，再开放技能描述。v1 校验器拒绝未知字段，不能先向它塞入 v2 配置。技能文档、校验器和实际执行报告必须同步更新。

## 实现顺序

1. 用自建简单零件和官方样例验证尺寸导入、DimXpert 注解导入、自动排列、DWG 导出回读及 PDF。结果包括失败和覆盖缺项，源模型保持完整。
2. 检查参考库样图，建立板类、轴类、支架类布局及 A4/A3/A2 模板配置；完成初始视图与尺度候选选择。
3. 接入特征覆盖清单、关联尺寸补齐、表格选择及局部/剖视需求，完成排版反馈和失败停止。
4. 接入一键集成执行、输出报告与异常恢复，用代表性模型验证，并对最终审核图执行独立盲重建。
5. 更新本地 skill 及 GitHub：只同步通用算法、配置、文档和合成测试；不上传真实模型、DWG参考文件、图纸或原始执行记录。

## 验收条件

每个样例按完整性、可读性及输出结果验收，不按标注数量打分。

- 源件文件摘要不变；工作副本与源几何一致；原生工程图重开后尺寸、注释和引用一致。
- 每个识别出的加工特征有充分几何定义或明确失败项；不从默认 DimXpert 规则新增未经指定的公差、基准或制造信息。
- 严格一张 A4/A3/A2，投影一致，文字/箭头符合所选模板且打印可读；无悬空、遮挡标题栏及妨碍阅读的重叠。
- 密集孔群表格的编号、位置、孔径、深度和数量与源事实一致，视图加表格足以理解形状。
- 真正回读实际 DWG，PDF确由其产生，PNG来自审核PDF；文字、符号、尺寸、关键轮廓和页面位置通过比对与渲染检查。
- 第一组开发验收样例覆盖板类孔槽台阶、轴类多直径/圆角及支架类剖视或局部需求；至少一个密集表格样例和一个单页放不下的失败样例。
- 代表性盲重建只收到冻结的审核图和通用工具，先冻结重建模型，再接触源模型比较；分别报告几何差异、解释歧义及缺少的制造要求。
- 缺少制造要求的成功草稿标为 `DRAFT_REVIEW_REQUIRED`；几何覆盖或布局失败为 `FAILED`；输出链路部分失败为 `PARTIAL_EXPORT_FAILED`。文件存在、API返回成功或原生通过都不能代替最终交付验收。

当前设计不承诺任意零件都能完整自动出图。复杂功能公差、任意曲面制造意图、复杂偏移剖视等超出已验证操作时，必须以具体特征和原因报告。
