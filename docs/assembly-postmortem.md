# 完整机械手装配复盘：接口成功不等于装配正确

## 事实与两轮结果

输入由授权的原装配派生，重建 8 种自制件，保留 7 种采购叶级零件。完整树有 26 个叶级零件实例及 6 个采购子装配实例，16 个顶层组件。顶层新建 43 条配合；另外 12 条采购子装配内部配合实例是继承的，不能计入新建成功率。

两轮初始放置都采用源组件的旋转矩阵，只打散非基准组件的平移。因而这是有原始朝向提示的装配验证，不是任意随机姿态或仅凭 PDF 的装配搜索。

| 验证项 | 第一轮 | 方向转换修正后 |
|---|---:|---:|
| 新建 API 返回成功 | 43/43 | 43/43 |
| 保存重开后无错误的配合 | 43/43 | 43/43 |
| 平行/同轴/重合的无向残差 | 合格 | 合格 |
| 全组件符合输入位姿和朝向 | 不合格 | 合格 |
| 干涉组件对数 | 12 | 2，与原模型一致 |
| 整体静态装配结论 | 失败 | 通过 |

第一轮最大顶层原点偏差约 793.82 mm，旋转矩阵元素最大差为 2；不是可忽略的误差。第二轮最大顶层平移差约 6.25×10^-12 mm，朝向差为浮点误差量级。这些小量只表示数值比较吻合，不是实物加工精度声明。

## 根因定位

起初程序按源面与重建面 `Surface.PlaneParams` 的法向是否相反，翻转配合的 aligned / anti-aligned 条件。

但是 **底层曲面参数方向不是实体面的外法向**。同一个实体边界，底层平面的参数化可以反向，拓扑上的面方向会补偿它，使真实外法向保持不变。平面配合应根据实体面朝向判断。官方对齐说明以选中面的法向定义平面同向/反向；圆柱另有轴向约定。[SolidWorks：Mate Alignment](https://help.solidworks.com/2025/english/solidworks/sldworks/c_Mate_Alignment_SWassy.htm)

本地诊断分别读取原/新配合的 `Face.Normal`、`Surface.PlaneParams`、`FaceInSurfaceSense()`、实体参数与组件变换。一个明确例子：某对应面的原底层法向为 `(0,0,-1)`，重建后为 `(0,0,+1)`，但两者实体面外法向均为 `(0,0,+1)`。按底层法向取反就把本应保留的对齐条件改错了。

第一版因此错误转换了 12 条平面配合的方向。SolidWorks 仍能找到满足无向几何约束的翻转解；诊断还显示部分配合的最终对齐状态不同于最初请求值。因此创建返回码和最终“无错误”状态都没有证明设计意图正确。

## 实际修正与适用条件

八种重建件在装配前已通过原件布尔几何等价检查，选中面的几何也被正确对应。因此对这些对应边界平面，保留源外法向关系，不因底层平面参数反向而翻转配合。圆柱轴方向转换保持独立。

此次只改这一点，没有改零件几何、没有固定所有组件、没有删除冲突配合来凑数。另存第一轮失败装配，再从相同输入重新建立 43 条配合；最终位姿、朝向、干涉对与体积恢复源基线。

当前代码的 `if(kind=="plane") flip=0` 是在“实体已证明等价、边界面已正确对应”的前提下成立，**不是可以套用于任意两个面的通用修复**。后续通用实现应显式存储/比较外法向、面意义及坐标系，并检查有向关系。

## 为什么看到局部模块整体装上去

确实存在两种“成组移动”，但性质不同：

1. **采购子装配作为组件整体插入。** RB1006、ZSE30A、ZH05BS 等本来就是现成 SLDASM。保留内部层级和配合后作为顶层组件插入。这不是本轮新建了这些内部结构。6 个采购子装配实例中有些内部零件固定，没有新建配合。
2. **顶层配合形成连通组合后一起移动。** 日志中先建立 050—047 的 3 条配合，再建立 050—059 的 3 条配合；这三件形成局部连接组。随后第 7—9 条配合把 047 接到固定的 046，已连接的 050、059 会随 047 一起定位。因此画面像是先装好模块再整体装上去。

```
阶段 A：050 ── 047       先配合两个未固定件
阶段 B：059 ── 050 ── 047
阶段 C：059 ── 050 ── 047 ── 046（固定基准）
```

阶段 A/B 的自制件仍是总装中的顶层组件，脚本没有新建对应的子装配文档，也没有执行“形成新子装配”。这是配合图连接后，求解器整体移动联动组件；不能把它描述为已验证的自动模块识别/自动装配工艺规划。

## 可复用沉淀

- 每个配合记录实体类型、局部几何、真实方向、组件坐标、期望接触侧，避免仅依赖旧 Face ID。
- 检查维度从“API → 特征 → 几何残差”扩展到“有向关系 → 全局位姿 → 干涉 → 自由度”。无向的轴线距离无法识别 180° 翻转。
- 可以考虑按固定基准向外逐模块装配，以减少自由漂移并便于录像解释；这是后续优化建议，不能声称本轮已实现自动拓扑排序。
- 继承采购子装配和本轮新增模块必须分开计数。一个模块动起来，不一定有一个对应的 SLDASM 文件。
- 第一轮失败样本、日志和第二轮修正应保留，最终视频可以只保留成功过程，但报告必须注明剪辑范围与首次失败。

本地证据依据：首次/最终配合与装配验证、direction_probe.json、component_name_map.json 等。按用户要求不上传这些执行结果，只公开本复盘与诊断代码。
