# Native annotation layout

Use after native views/sections and model dimensions exist in a saved drawing. This is an additional operation; it does not automatically import all feature dimensions or infer missing manufacturing intent. Preserve native associated dimensions and conventional view/section callouts where readable. For numerous or cluttered dimensions, a coordinate/feature table or mixed view/table presentation is allowed. Read the [confirmed drawing profile](manufacturing-draft-profile.md) for the dense-dimension decision and current implementation boundary. The layout runner has no table-creation operation; use the main executor's supported general table contract or add a reusable operation before requesting unsupported table types.

Run `scripts/layout.ps1 -Plan <absolute JSON> -Python <executable> -InteropPath <SolidWorks interop DLL>` in Windows PowerShell 5.1. With scriptblock invocation set `SW_DRAWING_SKILL_ROOT` to the installed skill. Use a new output directory. Close the saved input drawing before running; an already-open input is rejected to preserve the user's editing session. Modified source models are also rejected.

Plan fields: absolute `source`, `facts`, `input` (saved SLDDRW), `output` (new SLDDRW), `report`, `pdf`, `pdf_report`; `sheet_mm: [width,height]`; arrays `keep`, `linear`, `leaders`, `note_moves`, `view_moves` (empty arrays permitted).

Preparation normalizes paths to Windows separators. Use native Windows paths for other SolidWorks calls too: locally `NewDocument` rejected a forward-slash template path while the equivalent backslash path succeeded.

- `keep`: `{view, name, expected_si, position_mm?, prefix?, suffix?, layout?}`. `name` is the full dimension name without the final drawing suffix. This list is exhaustive: other dimensions are removed. Select one suitable view per model dimension unless a justified repetition improves readability. Review the inventory before authoring this list.
- `linear`: `{id, view, direction, a, b, expected_mm, position_mm}`. Each selected entity descriptor is `{kind: "line" | "circle", edge_id}` from source facts, or `{kind:"datum_edge", axis:0|1|2, value_mm}` for a visible straight datum edge. The executor compares the actual associated dimension with `expected_mm`; mismatches fail.
- `leaders`: `{view, text, edge:{kind,edge_id}, position_mm}`. Conventional notes attach to the uniquely matched visible source edge; they are not associative Hole Wizard callouts.
- `note_moves`: `{view?, text, position_mm, new_text?, at_mm?, delete?}`. `at_mm` disambiguates duplicate note text. `view_moves`: `{view,position_mm,scale?,angle?}`; changing a view requires rechecking all its annotation positions.

Optional `layout` on a dimension: `{axis:0|1, span_mm:[start,end], row_mm}` or `{axis,span_mm,group,base_mm,sign:1|-1,gap_mm:8,padding_mm:3}`. These are **sheet coordinates**, after projection and scale. Supply them from verified geometric anchors, not measured pixels. Missing `position_mm` is filled with the span midpoint and an external row. Nonoverlapping spans in one group share a row; overlapping spans use the next row. Explicit positions are preserved and checked. Text outside its supplied witness span fails unless `outside_span_reason` records an intentional placement reviewed visually. This check covers supplied spans only; it does not automatically discover witness endpoints. Eight millimetres is a configurable starting spacing, not a claimed drafting standard.

Preflight rejects invalid positions, duplicate retained dimensions and text outside supplied spans. It does not verify that authored spans match source geometry. Postflight compares dimensions, prefix/suffix, positions and note text before/after reopen, retained expected values and dangling annotations. A `.run.json` preserves execution status and failure diagnostics. A `.plan.json` preserves resolved positions. Inspect the execution actions for every requested note edit (unmatched note text may produce no edit), source-edge attachment identity, view changes, PDF text and rendered linework: checking anchors alone cannot prove text boxes or extension lines are clear. Prefer explicit fact edge IDs over longest-edge datum selection when multiple edges share a coordinate.

The borrowed ideas are declarative batching, external dimension rows and early validation from [Text to CAD](https://github.com/earthtojake/text-to-cad) / cadgen. No cadgen dependency is required and its renderer is not used. SolidWorks retains geometry projection, sections, association and editable output.

## Completeness and optional reconstruction test

Maintain a private feature-to-view/callout/table-row checklist in the run directory: exterior, pockets/steps, each hole group (face, position, size, depth, through/blind), radii, chamfers and reliefs. Mark uncertainty explicitly. This QA checklist is distinct from any deliberate dimension or hole table printed on the engineering drawing. Table rows count as coverage only when their feature correspondence and required values are verified. Counts alone do not certify coverage. Add informative sections/opposite views, and detail views when supported, wherever hidden shape or depth remains ambiguous.

When the user requests a blind loop, freeze the final PDF hash, give a fresh reconstruction worker only that PDF plus generic CAD tooling, and freeze its editable model and interpretation report before revealing source geometry or comparison results. No source facts, old reconstruction or model-specific scripts go to that worker. A revision by the same worker is not a new first-pass blind result.

Compare only after a geometrically justified rigid registration; preserve source and candidate hashes. A Boolean failure at that registration is an invalid measurement, not a high error percentage. Do not substitute a different rotation merely because its Boolean succeeds. An independent kernel may be used with explicit format/conversion/tolerance limitations. Report symmetric difference and independent volume discrepancy separately; empty Boolean residual does not establish zero surface deviation.

Retain first failures and distinguish iterated reconstruction results from fresh first-pass results.
